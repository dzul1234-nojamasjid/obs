OBS Pocket Guide

1. Pengenalan & Asas OBS 1. Intro & OBS Basics

Selamat datang ke panduan OBS Studio untuk Masjid. OBS adalah perisian percuma untuk siaran langsung ke Facebook atau YouTube.

Welcome to the OBS Studio guide for the Mosque. OBS is free software for live streaming to Facebook or YouTube.

Perkara Penting:Key Points:

  • OBS memisahkan antara Preview (apa yang kita lihat) dan Program (apa yang penonton lihat). OBS separates Preview (what we see) and Program (what viewers see).
  • Gunakan OBS Studio 31 jika boleh, kerana versi 33.0.1 mempunyai isu audio. Use OBS Studio 31 if possible, as version 33.0.1 has audio bugs.
Nota: Jangan takut untuk mencuba. Ramai juruteknik bermula dari kosong. Note: Don't be afraid to try. Many technicians start from scratch.

2. Konsep Scene & Source2. Scene & Source Concept

  • Scene (Panggung): Bekas untuk menyusun paparan. Contoh: "Scene Ceramah", "Scene Iklan". Scene (Stage): Container to arrange displays. E.g., "Lecture Scene", "Ad Scene".
  • Source (Barang): Bahan dalam Scene. Contoh: Kamera, Gambar, Audio. Source (Item): Materials in the Scene. E.g., Camera, Image, Audio.
Penting: Jika Tuan memadam (Delete) Source, ia hilang dari semua Scene. Sembunyikan dengan ikon Mata sahaja. Important: If you Delete a Source, it disappears from all Scenes. Just hide it using the Eye icon.

3. Panduan Setup Asas3. Basic Setup Checklist

  1. Kamera: Klik + > Video Capture Device.Camera: Click + > Video Capture Device.
  2. Mikrofon: Klik + > Audio Input Capture.Microphone: Click + > Audio Input Capture.
  3. Suara Komputer: Klik + > Audio Output Capture.PC Sound: Click + > Audio Output Capture.
  4. Warna Kuning: Klik kanan Kamera > Filters > Color Correction.Yellowish Color: Right-click Camera > Filters > Color Correction.
  5. Facebook: Pergi ke Settings > Stream dan masukkan Stream Key.Facebook: Go to Settings > Stream and enter Stream Key.

4. Rahsia Audio & Mute4. Audio & Mute Secrets

  • Butang Mute (Speaker): Menyekat bunyi ke siaran Facebook.Mute Button (Speaker): Blocks sound to Facebook broadcast.
  • Butang Monitoring (Fon Kepala): Benarkan Tuan dengar di pembesar suara laptop.Monitoring Button (Headphone): Allows you to hear on laptop speakers.
Amaran: Jangan tandakan "Enable" untuk "Video Capture Device" di Advanced Audio Properties (elak echo). Warning: Don't tick "Enable" for "Video Capture Device" in Advanced Audio Properties (avoid echo).

5. Kuasai Studio Mode5. Mastering Studio Mode

  • Preview (Kiri): Sediakan bahan. Audio TIDAK KELUAR di sini.Preview (Left): Prepare materials. Audio DOES NOT PLAY here.
  • Program (Kanan): Siaran sebenar. Penonton lihat ini.Program (Right): Actual broadcast. Viewers see this.
  • Transition (Tengah): Butang untuk pindah dari Preview ke Program.Transition (Center): Button to move from Preview to Program.
Tip: Nak stop video? Pilih Scene lain di Preview, tekan Transition. Tip: Want to stop a video? Select another Scene in Preview, press Transition.

6. Masalah Sumber Media6. Media Source Issues

Gambar Skrin Hitam?Image Black Screen?

  • Guna Image Source (bukan Media Source) untuk fail JPG/PNG.Use Image Source (not Media Source) for JPG/PNG files.
  • Jangan simpan gambar dalam folder OneDrive.Don't store images in OneDrive folders.

Video Tiada Bunyi?Video No Sound?

  • Untick "Restart playback when source becomes active".Untick "Restart playback when source becomes active".
  • Tanda Loop untuk ulang video.Tick Loop to repeat video.

7. Isu OBS Versi 337. OBS v33 Bug Issues

OBS versi 33.0.1 ada isu Audio Monitoring tak berfungsi.

OBS version 33.0.1 has a non-functioning Audio Monitoring issue.

Cara Baiki:How to Fix:

  • Matikan Desktop Audio: Pergi Settings > Audio, tukar ke Disabled.Disable Desktop Audio: Go Settings > Audio, change to Disabled.
  • Downgrade OBS: Pasang semula OBS versi 31.Downgrade OBS: Reinstall OBS version 31.
Normal: Bunyi tak keluar di Preview. Ia hanya keluar bila tekan Transition ke Program. Normal: No sound in Preview. It only plays when you press Transition to Program.
